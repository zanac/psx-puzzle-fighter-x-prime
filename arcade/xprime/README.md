# X' (arcade) by KScl

These are the sources of Super Puzzle Fighter 2 X' for the arcade (CPS2) set
`spf2t`, by Katie Sinclaire (KScl):
https://github.com/KScl/puzzle-fighter-x-prime (commit 46f41a5).
They are unchanged, under their own license (`LICENSE`, zlib). The arcade
build applies them first, then the X" patches in `arcade/src`; with no X"
patches, `tools/arcade.py` gives the same ROMs as the published X' set
(`spf2xpri`: pzfxp.03 f205a7da, pzfxp.04 4177aadd, gfx 930b0ec7, 769377ad,
5a79233f, 42cfc9e2).
